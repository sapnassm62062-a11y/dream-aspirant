# 🚀 Dream Aspirant

**Dream Aspirant – Dream. Prepare. Achieve.**

Dream Aspirant is a full-stack exam preparation platform designed to help students prepare for government exams with study materials, previous year questions, mock tests, AI-powered interviews, and performance tracking.

---

## 🌟 Features

### 👨‍🎓 Student Features

- 🔐 User Registration & Login
- 👤 Profile Management
- 📚 State-wise Exam Preparation
- 📝 Previous Year Questions (PYQ)
- 📖 Study Materials & Notes
- 🎯 Mock Test System
- 📊 Result & Performance Tracking
- 🤖 AI Interview Practice
- 📄 AI Interview Report Generation
- 💳 Online Payment Integration


### 👨‍💼 Admin Features

- 🔑 Admin Role Management
- 📚 Manage Study Materials
- 📝 Manage Subjects
- 🎯 Manage Exams
- 📄 Upload PYQ
- 👥 Manage Users
- 📊 Monitor Student Activities
